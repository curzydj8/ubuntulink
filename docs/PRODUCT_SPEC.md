# UbuntuLink 产品规格（阶段 0，2026-10-11）

## 1. 项目定位

面向普通用户的安卓应用：通过手机远程查看、操作自己授权的 Ubuntu 电脑，
并实时监控硬件与系统运行状态。最终交付真正可运行、可测试、可扩展的完整项目。

## 2. 核心能力（必须实现）

1. 安卓手机连接 Ubuntu 电脑。
2. 安卓端实时显示 Ubuntu **当前真实桌面**（非模拟、非截图占位、非无关虚拟桌面）。
3. 手机操作 Ubuntu 桌面：鼠标点击/移动/滚动、键盘输入。
4. 实时监控：CPU、内存、GPU、磁盘、网络、温度、系统运行状态。
5. 同一局域网 + 跨互联网连接。
6. 优先自动建立安全的点对点连接；直连失败用中继。
7. Ubuntu 端 Go 轻量收集与通信程序。
8. 安卓端交付可安装 APK。
9. 清晰模块结构、完善错误处理、真实测试记录、安全机制。
10. 预留多设备管理、文件传输、系统诊断扩展能力（优先核心功能）。

## 3. 零配置要求（用户明确）

以现有设备为依据，安卓端无需手动配置即可看到 Ubuntu 信息。
实现路径：手机与 Ubuntu 已同处 Tailscale 虚拟局域网（100.105.107.86/100.101.73.16），
手机 Tailscale 在线后 App 自动发现并直连 agent，不要求用户填 IP、开端口。
局域网 mDNS 发现作为同 Wi-Fi 下的辅助路径。

## 4. 安卓端页面

1. 首页：设备列表、连接状态、最近连接。
2. 添加设备：局域网发现、二维码配对、手动配对。
3. 设备详情：系统版本、在线状态、硬件概览。
4. 远程桌面：真实桌面 + 触控/键盘/缩放/方向适配。
5. 硬件监控：CPU/内存/GPU/磁盘/网络/温度及趋势。
6. 连接设置：画质、帧率、连接方式、流量提示。
7. 安全设置：授权管理、取消配对、退出会话。
8. 日志与诊断：失败原因、延迟、丢包、版本（不泄露敏感内容）。

所有状态（连接中/失败/权限不足/离线/数据不可用）必须有清晰提示。
适配手机与平板。

## 5. 硬件监控指标要求

| 指标 | 数据来源（Linux） | 缺失时处理 |
|---|---|---|
| CPU | /proc/stat、使用率/核心数/频率 | 频率不支持则标不可用 |
| 内存 | /proc/meminfo | — |
| GPU | Intel 核显：sysfs/i915（尽力）；无独显 | 标"不可用"，不用 0 冒充 |
| 磁盘 | statfs / df | — |
| 网络 | /proc/net/dev、网卡状态 | 断开则标状态 |
| 温度 | /sys/class/thermal、hwmon（`sensors` 未装） | 无传感器则标不可用 |
| 系统 | /etc/os-release、uname、uptime | — |
| 连接 | RTT、帧率、连接类型、丢包 | 实测值 |

每项数据标明单位、更新时间、可用状态。

## 6. 非目标（第一版不做）

- 任意 Shell 命令执行（安全原因，第一版不提供）。
- 公网中继服务部署（无服务器；阶段 5 明确标记）。
- 多设备管理、文件传输、系统诊断（预留扩展点）。
- iOS 客户端。

## 7. 已知技术限制（阶段 0）

- Wayland 下传统 X11 截屏/注入（xwd/xdotool）不可用，必须走 portal 体系。
- 构建/测试 Runner 不在图形会话内，桌面捕获类测试需在用户会话中进行。
- Intel 核显无 nvidia-smi 式工具，GPU 指标大概率不可用。
- `sensors` 未安装，温度依赖 sysfs，需实测。
- 手机 Tailscale 节点当前离线（16h），联调前需用户上线。

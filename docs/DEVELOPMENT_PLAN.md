# UbuntuLink 开发计划（阶段 0，2026-10-11）

## 阶段 0：检查现有环境与项目 —— 进行中（本轮）

- 环境检查报告、目录结构、已有文件作用、桌面会话类型、已知技术限制。
- 更新产品规格、架构、安全、开发计划文档。
- 不得大规模生成业务代码。

## 阶段 1：Go Agent 基础功能

- 安装 Go 工具链（阶段 0 确认未安装）。
- 最小可运行 agent：版本/健康检查、真实系统信息、CPU/内存/磁盘/网络监控、
  GPU/温度（尽力，标可用状态）、结构化日志、配置文件、单元测试。
- 验收：编译通过；本机运行读出真实数据并与系统工具交叉验证；
  不可用指标正确标示；测试真实记录。

## 阶段 2：设备配对与安全通信

- 配对码（有效期+尝试限制）、设备身份、会话认证、WSS 通信。
- 验收：未授权拿不到受保护数据；错误配对码被拒；配对可过期/撤销；
  断线重连正确；安全测试真实记录。

## 阶段 3：Android 监控应用

- 设备列表、配对界面、设备详情、实时监控页、错误提示；生成可安装 APK。
- 验收：APK 可装；连真实 agent；数据来自真实设备；断线状态正确；无模拟数据。

## 阶段 4：远程桌面观看原型【2026-10-11 修订：只看不控】

- 技术验证优先：portal ScreenCast 真实捕获 → 传输 → Android 显示；
  记录实际帧率、延迟、CPU 使用率；Wayland 结果单独记录。
- 不实现输入注入（只读原则），RemoteDesktop portal 不需要评估。
- 若成熟方案构建失败，查明原因记录，不伪造通过。
- 验收：显示真实当前桌面且持续更新；结束会话后观看通道关闭；
  Ubuntu 端有可见的观看中状态。

## 阶段 5：跨互联网连接

- 信令/直连协商/中继。Tailscale 路径先行验证（双端已在网）。
- 验收：LAN 正常；至少两种真实网络环境验证跨网；记录实际路径；
  无公网服务器则明确标记未验收，不用本地模拟代替。

## 阶段 6：性能、安全与兼容性优化

- 长稳运行、前后台切换、锁屏重连、弱网、画质/流量/电量、多设备、
  权限最小化、日志脱敏、异常退出资源释放。按实测修复。

## 阶段 7：发布准备

- Release 构建、安装启动测试、版本号、许可证清单、部署/安全/排障文档、
  真实测试报告、已知限制、升级策略。只有实测通过的功能才标完成。

## 测试状态词（统一）

未开始 / 开发中 / 已实现，未验证 / 测试通过 / 测试失败 / 受环境或外部依赖限制。
